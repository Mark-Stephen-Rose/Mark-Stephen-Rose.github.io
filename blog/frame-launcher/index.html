Building a Photo-First Home Screen for My TV

Android JavaScript Testing Open Source

I wanted less clutter on my TV, and I wanted using it to feel enjoyable instead of like being bombarded with ads and rows of content I never asked for.

So I built Frame Launcher, a home screen for Android TV streaming sticks that puts your apps over a full-screen photograph, with frosted-glass panels, an optional art mode and a clock that stays readable. It feels more like a picture frame than a store shelf.

Making text readable on any photo

A launcher is mostly text on top of a picture, and pictures are unpredictable. A bright sky behind white text is unreadable. So I measured the brightness of each of the 14 bundled wallpapers and stored a small readability profile for each one. The launcher uses it to choose light or dark text and how strongly to tint the glass panels. It’s a small feature that decides whether the whole thing feels polished or broken.

Testing something with no mouse

The interface is a web page that is driven by a TV remote. I wrote headless-browser tests that press arrow keys the way a remote would. They now cover every layout and Settings option, plus long random sequences of button presses, and they run in CI before the APK is built. That caught problems no amount of clicking around would have: a focused tile clipped at large font sizes, and an app that could end up both pinned and hidden.

Programming with clinical data got me very comfortable building checks to make sure the data in my programs is trustworthy, and I carried that habit straight into this project. I trust the unglamorous checks more than the demo.

Being honest about limits

The Home button can’t be fully taken over on this kind of device, so I used an accessibility service that returns to the launcher when the stock home screen appears. It works, but the stock screen flashes for a moment first. I documented that in the README instead of hiding it.

I also kept the app small on purpose. There are no ads, no analytics and no account, and the only network features (a VPN status pill and an update check) are off by default. I decided against weather, notifications and ads because each one would have made it heavier and less private, which is the opposite of why I started.

Credit and licensing
